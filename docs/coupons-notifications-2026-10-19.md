# คูปองที่เก็บไว้และแจ้งเตือนแบบขยาย

## การใช้งาน

- ลูกค้าเปิดโปรไฟล์ → คูปองของฉัน (`/customer/coupons`) สลับดูคูปองที่เก็บไว้และคูปองให้เก็บ การเก็บผูกกับบัญชี ไม่ใช้สิทธิ์และไม่เลือกส่วนลดให้อัตโนมัติ
- หน้าชำระเงินเลือกได้หนึ่งใบจากคูปองที่เก็บไว้ หรือเลือกไม่ใช้คูปอง เปลี่ยนตัวเลือกแล้วใบเดิมถูกแทนที่
- ตรวจร้าน ยอดอาหารขั้นต่ำ วันเริ่ม/หมดอายุ เพดานส่วนลด สิทธิ์รวมและสิทธิ์ต่อบัญชี คูปองที่ใช้ไม่ได้ยังปรากฏพร้อมเหตุผล ถ้าใบที่เลือกใช้ไม่ได้ต้องเลือกใหม่หรือเอาออกก่อนยืนยัน ไม่เปลี่ยนเป็นราคาเต็มให้เงียบ ๆ
- การยกเลิกคืนสิทธิ์ของ claim ออเดอร์นั้นครั้งเดียวตามพฤติกรรมกู้คืนเดิม โดยคืนทันทีด้วย คูปองที่หมดอายุ/ปิดใช้งานยังใช้ไม่ได้ และออเดอร์ที่รับอาหารแล้วไม่คืนสิทธิ์
- แจ้งเตือนลูกค้าและเจ้าของร้านกดหัวรายการเพื่อขยาย อ่านรายละเอียด/เวลา/สถานะที่ทราบ แล้วกดปุ่มเปิดออเดอร์หรือคูปองที่เกี่ยวข้อง บันทึกว่าอ่านแล้วหลัง API ตอบสำเร็จ มีปุ่มลองใหม่เมื่อบันทึกไม่ได้

## API และความถูกต้อง

- `GET /api/v1/customer/coupons`: เฉพาะที่บัญชีนี้เก็บไว้ รวมใบที่หมดอายุ ปิดใช้งานหรือถูกลบ โดยแสดงว่าใช้ไม่ได้
- `POST /api/v1/customer/coupons/:promotionId/collect`: 201 เมื่อเก็บใหม่ / 200 เมื่อเคยเก็บแล้ว unique index `(user_id, promotion_id)` ป้องกันซ้ำ
- Checkout รับ `couponId` หนึ่งค่าและ `couponCode` ที่ตรงกัน ตรวจ ownership และคำนวณราคาที่เซิร์ฟเวอร์ ปฏิเสธ array/object/ฟิลด์ใช้หลายใบ ใช้ ID แยกใบที่มีรหัสเดียวกันคนละร้านได้
- Quota กับใบเสร็จ claim อัปเดตแบบ atomic ป้องกันแย่งสิทธิ์ข้ามร้านและคืนซ้ำ ตรวจเงื่อนไขส่วนลดที่อ่านกับค่าตอน claim อีกครั้งก่อนตัด Wallet
- การแก้โปรโมชั่นโดยแอดมินไม่เขียนทับ counter หรือ map สิทธิ์ที่ checkout อาจเพิ่งเพิ่ม
- คำขอชำระเงินที่ผลยังไม่แน่นอนใช้ key/yอด/รายการเดิมเพื่อกู้ผล ไม่ตัดใหม่เพราะคูปองถูกใช้ไปแล้ว การเริ่มออเดอร์ใหม่ต้องรับทราบคำขอเก่าที่ยังไม่ทราบผลก่อน
- รายการคูปองจาก server ไม่ใช้ localStorage เป็น authority และไม่ข้ามบัญชี ลิงก์แจ้งเตือนจำกัดปลายทางตามบทบาท

## ขอบเขตการตรวจ

ทดสอบ pure logic, React lint และ production build รวมถึง HTTP จริงกับฐาน MongoDB สุ่มแยกจาก production สำหรับ collection, checkout, quota concurrency, cancellation และ compensation เก็บข้อมูลพร้อม indexes ก่อนลบฐานทดสอบ ไม่ส่งอีเมลหรือ Push ออกจริงจากชุดทดสอบ

การทดสอบ UI ในเบราว์เซอร์ของเครื่องนี้ยังถูก saved origin permission ปฏิเสธ จึงไม่อ้างว่าทดสอบการคลิกหรือหน้าตาบนเบราว์เซอร์จริงผ่าน และไม่ข้ามข้อจำกัดนี้ด้วยเครื่องมืออื่น
