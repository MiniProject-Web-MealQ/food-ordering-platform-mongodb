## ผลทดสอบรอบแรก

- Backend: 41 ผ่าน และ MongoDB test แบบ opt-in ข้าม 1 ตามค่าเริ่มต้น
- Frontend: 8 ผ่าน, lint ผ่าน, production build ผ่าน
- Integration: workflow 10 กลุ่ม, regression 9 กลุ่ม, signup OTP 7 กลุ่ม, extensions 8 กลุ่ม ผ่าน
- รันชุด Backend/integration เดียวกันบน Pi ARM64 กับ MongoDB 4.4.18 ผ่าน ใช้ฐานข้อมูลชื่อสุ่มและ SMTP จำลอง ไม่ใช้ Gmail ส่งอีเมลใน automated tests
- Extensions ตรวจ HTTP จริง: OTP เปลี่ยนอีเมล/อายุ/รหัสซ้ำ/session เดิม, วัตถุดิบ/สูตร/ownership, สั่งซ้ำ/หมด/คืน stock, recovery จาก ledger สูญหาย, coupon/queue, ยอดขาย, inbox ข้ามเครื่อง และรูป cacheable
- Runtime production dependencies: npm audit --omit=dev ไม่พบช่องโหว่ ณ เวลาตรวจ ส่วน development nodemon chain ยังมี advisory ของ braces จึงไม่ถูกติดตั้งใน production image
- Gmail บน Pi: SMTP authentication ผ่าน โดยไม่ได้ส่งอีเมลทดสอบ
- Browser localhost: catalogue และ register โหลดได้หลังแบ่ง chunks

ผลรอบต่อมา: ผู้ใช้ยืนยัน Google Login บนโดเมนจริงแล้ว Gmail จริงผ่าน OTP สมัคร/เปลี่ยนอีเมล/รีเซ็ตรหัสผ่าน และ Web Push บน Chrome คอมพิวเตอร์ได้รับขณะปิดแท็บและกดเปิดเว็บได้แล้ว ทดสอบ production API workflow 10/10 กลุ่ม พร้อมบัญชีลูกค้า/ร้านค้า Demo ที่ใช้งานได้ อีเมล HTML ใหม่มี text fallback และ Web Push เพิ่ม receipt กันการส่งซ้ำรายอุปกรณ์ ดู [live acceptance](live-acceptance-2026-10-19.md), [Pi รุ่นล่าสุด](pi-deployment-2026-10-19.md) และ [การสำรองอัตโนมัติ](backups-2026-10-19.md) ในรอบนั้นยังไม่ได้ทดสอบ iOS/Android จริง ส่วนผล Apple รอบใหม่อยู่ด้านล่าง และ PromptPay/Wallet ยังคง Demo ตามคำสั่ง
